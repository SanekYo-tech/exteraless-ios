# Волна 1 — ожидаемое поведение UI и визуальная проверка

До записи экранов ожидается:

- Главные настройки: одна строка «Плагины», обычные отступы и иконка Telegram;
  тап открывает менеджер в текущем navigation stack.
- Менеджер: стабильные состояния loading/empty/error/loaded, имя и версия
  плагина не перекрывают toggle. Ошибка загрузки видима, switch отражает
  действительное состояние. Import и удаление обновляют список однократно.
- Экран настроек: заголовки/разделители, switch, selector, input, slider и text
  читаемы в light/dark; значения после изменения и повторного открытия сохранены.
- Back-навигация не оставляет overlay или клавиатуру поверх списка. Длинные
  названия и Dynamic Type не обрезают кнопки и сообщения ошибок.
- Стандартные переходы Telegram: элементы движутся вместе; нет вспышки цвета,
  двойной строки, смены loaded до фактического завершения или зависшего spinner.

XcodeBuildMCP в текущем Windows-сеансе отсутствует. Визуальная проверка по
записи/кадрам остаётся явным пунктом приёмки на устройстве/доступном Mac после
контрольной IPA. Успех компиляции и unit tests сам по себе её не подтверждает.
